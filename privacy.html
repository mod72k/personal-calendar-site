プライバシーポリシー

Personal Calendar（iPhone アプリ）／制定日 2026年10月12日

1. 利用する Google のデータ

利用者が Google アカウントでログインして許可した場合に限り、Google Calendar API を通じて次のデータを利用します。

  • カレンダーの一覧（名前・色・書き込みできるか）：https://www.googleapis.com/auth/calendar.calendarlist.readonly
  • 予定（件名・日時・場所・メモ・繰り返し・通知の設定）の表示・作成・編集・削除：https://www.googleapis.com/auth/calendar.events
  • ログインしたアカウントのメールアドレス（どのアカウントの予定かを見分けるため）

2. 使い道

アプリの画面に予定を表示すること、および利用者が操作したとおりに予定を作成・編集・削除することにだけ使います。広告、分析、機械学習の学習などには使いません。

3. 保存する場所

  • ログインの情報（Google が発行するトークン）は、端末のキーチェーンに保存します。
  • 予定のデータは、表示のためにアプリの動作中だけ端末のメモリに置きます。
  • 表示の設定（カレンダーごとの表示・非表示など）は、端末の中にだけ保存します。

4. 第三者への提供

Google のデータを、Google 以外のサーバーや第三者へ送ったり、売ったり、共有したりしません。アプリの開発者も、利用者の予定を見ることはできません。

5. 削除・アクセスの取り消し

  • アプリの設定画面でアカウントをログアウトすると、端末からログインの情報を消し、Google への許可も取り消します。
  • Google アカウントの「セキュリティ」→「サードパーティ製のアプリとサービス」からも、いつでもアクセスを取り消せます。
  • アプリを削除すると、端末に保存した表示の設定は消えます。ただし、iPhone の仕組み上、キーチェーンのログイン情報は端末に残ることがあるため、削除する前にログアウトするか、上の方法で Google 側から取り消してください。

6. Google API サービスのユーザーデータに関するポリシー

このアプリが Google API から受け取った情報の利用と、ほかのアプリへの受け渡しは、Google API Services User Data Policy（Limited Use の要件を含む）に従います。
